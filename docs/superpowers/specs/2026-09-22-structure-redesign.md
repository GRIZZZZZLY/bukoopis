# Новая структура интерфейса — карта (черновик на согласование)

Дата: 2026-09-22. Статус: черновик, код не тронут.
Решение автора: пересобираем структуру, визуальный стиль («Чернильная ночь») оставляем.
Мобильная раскладка вне рамок (решение 2026-07-31) — не трогаем.

## Зачем

Функции добавлялись по одной, и у каждой появился свой вход. Сейчас:
- у книги нет своей страницы, `/books/:id` сразу уводит в Studio;
- персонажи и предметы правятся в трёх местах;
- пять способов навигации одновременно, часть кнопок мёртвая;
- этап «Главы» собрал всё, что некуда было положить;
- в Кабинете около 60 кнопок и шесть блоков в правой колонке;
- один и тот же термин значит разное («Разбор» — четыре вещи).

Цель: у каждой вещи одно место, у каждого места одно имя.

## Комнаты

Четыре комнаты вместо семи разрозненных страниц.

### 1. Полка — `/books`
Без изменений.

### 2. Книга — `/books/:id` (новая, вместо перенаправления)
Дом книги. Слева короткое меню книги:

| Раздел | Что внутри | Откуда переезжает |
|---|---|---|
| Обзор | Следующий шаг одной кнопкой, путь по этапам, предупреждения | Дашборд со StudioPage |
| Главы | Список глав, новая глава, экспорт | Список со страницы этапа «Главы» |
| Канон | Персонажи, предметы, места, крючки, связи — **единственное место правки** | KnowledgePanel, редактирование из EntityStagePage |
| Заметки памяти | Бывшая «Доска сюжета», только чтение | PlotBoardPage |
| Настройки | Модели, профиль стиля, прочее | SettingsStagePage |

Одна кнопка «Добавить материалы» в шапке книги — единственный вход для загрузки текста, два режима внутри (см. вопрос 2).

### 3. Мастерская — `/books/:id/studio/<этап>`
Только этапы: Замысел, Мир, Лор, Персонажи, Предметы, План, Главы.
- Замысел получает свою страницу; дашборд уходит в «Обзор».
- Этапы «Персонажи» и «Предметы» предлагают и утверждают. Правка утверждённых — только в «Канон».
- Этап «Главы» — только статус готовности глав к письму; заглушка плана, канон, импорт и поиск отсюда уходят.
- Степпер этапов — единственная навигация внутри Мастерской.

### 4. Глава — `/books/:id/chapters/:cid` (бывший Кабинет)
- Верхняя панель: «Написать» с меню настроек (по беатам, остановить после беата, дописать с беата N) вместо пяти отдельных контролов.
- Три баннера памяти сливаются в один.
- Одна кнопка «Сохранить» плюс автосохранение.
- Правая колонка — вкладки, одна видна за раз: Отзыв критиков / Сцена / Канон главы / Версии / Чат / Стиль.
- План главы остаётся над рукописью, свёрнут по умолчанию.

## Навигация

- **Левая панель:** Полка, Книга, Профили стиля, Расходы. Больше ничего.
- **Крошки кликабельные**, с названием книги вместо `#id`: Полка / «Название» / Мастерская · План.
- Удаляем: дубли «Стиль» и «Использование» в верхней панели, мёртвую ⌘K, аватар без действия, сетку ссылок «Настройки / Главы» на StudioPage.
- Кнопки «← назад» остаются только там, где нет крошек.

## Визуальная чистка (стиль тот же)

- Токены в одном файле вместо двух.
- Одна система кнопок вместо трёх.
- Старые панели (критики, импорт, канон, план, поиск) — на карточки нового стиля.
- Удалить неиспользуемое: OutlinePanel, второй WarningsFeed, примитивы card/dot/kbd/progress.
- Подпись «Library Warm» в подвале — убрать.

## Волны

Каждую волну можно откатить отдельно. Оценки примерные.

1. **Словарь и навигация** — один файл подписей, левая панель, крошки, мёртвые кнопки. 1–2 дня.
2. **Дом книги** — страница `/books/:id`, разделы Обзор/Главы/Канон/Заметки/Настройки, один вход для материалов, разгрузка этапа «Главы». 3–4 дня.
3. **Глава** — вкладки справа, один баннер памяти, одно сохранение, меню «Написать». 2–3 дня.
4. **Визуальная чистка** — токены, кнопки, старые панели. 2 дня.

Метрика до/после: путь от новой книги до первой главы — сейчас около 14 кликов и 4 ожидания модели (docs/reviews/2026-09-19-independent-review-fable-appendix-frontend.md).
