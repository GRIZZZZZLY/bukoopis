# Дизайн: «Кабинет писателя» (Cozy Writer's Den)

Дата: 2026-07-12
Статус: одобрено пользователем (направление «поэтапно A → B», палитра «Чернильная ночь»)
Превью палитр: `docs/design/palette-options.html` (выбран вариант 2)

## 1. Цель

Превратить web-приложение из «обычного сайта» в уютный интерактивный кабинет/библиотеку/мастерскую писателя. Два этапа: сначала атмосферный слой поверх существующего Library Warm порта (этап 1), затем пространственная метафора «дом писателя» — комнаты (этап 2). Каждый этап заканчивается рабочим продуктом.

## 2. Принципы

1. **Метафора не ломает скорость.** Комнаты = существующие React-роуты. Навигация, hotkeys, структура URL — без изменений. Сценография — presentational-слой поверх, не замена IA.
2. **Всё выключаемо.** Настройка атмосферы: `полная | спокойная | выкл`. Хранение — `localStorage` (`bf-atmosphere`), применение — класс `atm-full | atm-calm | atm-off` на `<html>`. `off` = сегодняшний вид (чистый Library Warm на новой палитре). `prefers-reduced-motion` автоматически даёт поведение `calm`.
3. **Без тяжёлых зависимостей.** CSS + инлайн-SVG + один `<canvas>` для пылинок. Никакого WebGL/3D/анимационных библиотек. Ввод в TipTap не должен деградировать.
4. **Library Warm остаётся фундаментом.** Токены, типографика (Fraunces/Lora/Inter), компонентные классы сохраняются. Меняются значения токенов (палитра) и добавляются атмосферные слои.
5. **Dark academia, не китч.** Каждый скевоморфный элемент проходит проверку «помогает или мешает» на ревью.

## 4. Этап 1 — Атмосфера

### 1a. Визуальное ядро

- **Свет лампы**: радиальный тёплый градиент (`--color-brass-glow`) над рабочей зоной контента; виньетка по краям shell (inset-тень/градиент). Слой — `::before/::after` на shell-контейнере, `pointer-events: none`, `aria-hidden`.
- **Текстуры**: SVG-паттерн панелей (тёмное дерево/кожа в синей гамме) для sidebar и shell chrome — по образцу существующего `.paper-grain`.
- **Переходы-перелистывания**: View Transitions API через `react-router-dom@7` (`viewTransition` на Link/navigate). CSS `::view-transition-old/new` — fade + лёгкий поворот-сдвиг «страницы». Без поддержки API — обычный мгновенный переход (feature-detect, без polyfill).

### 1b. Механики

- **Фокус-режим** (ChapterPage): кнопка + hotkey. Sidebar и critique rail затухают до ~15% opacity, вокруг рукописи — круг света. Esc или потеря фокуса — выход. Реализация: CSS-класс на layout-контейнере.
- **Свеча-цель дня**: SVG-свеча в TopBar, высота воска = прогресс дневной цели слов. Контракт: `GET /api/writing-progress?date=YYYY-MM-DD` → `{ date, wordsAdded }`. Цель хранится в `localStorage` (дефолт 500), настройка в Settings. Реализация подсчёта `wordsToday` решается в плане: (а) дельта числа слов последних версий глав за день по `chapter_versions.created_at`, или (б) инкрементальная таблица `writing_days(date, words_added)` (миграция). Спека фиксирует только контракт endpoint.
- **Живые детали** (только `atm-full`):
  - пылинки в луче света — один `<canvas>` в AppShell, ~30 частиц, `requestAnimationFrame`, пауза при `document.hidden`, слой отключён на ChapterPage во время активного ввода;
  - мерцание свечи — CSS animation;
  - кот на «подоконнике» sidebar — инлайн-SVG-силуэт, состояния «спит/шевелит ухом/потягивается», редкие микродвижения (интервалы 30–90 с), по клику потягивается.

## 5. Этап 2 — Комнаты (порядок реализации)

Порядок: по возрастанию сложности, каждая комната — отдельный рабочий инкремент.

1. **Библиотека** (`BooksListPage`): деревянные полки (CSS), книги — вертикальные корешки (развитие существующего spine-card): толщина/высота зависят от числа глав, ляссе-закладка = прогресс (готовые/все главы), hover — корешок выдвигается (`translateY`), клик — открытие книги. «Новая книга» — пустой переплёт с «+».
2. **Кабинет** (`ChapterPage`): сначала штатный порт 3-колоночного layout (outline · `.ms-paper` · critique — уже запланирован и не входит в эту спеку), затем сценография: текстура стола под рукописью, лист с тенью и полями, чернильница-индикатор автосейва (капля при сохранении), критика — «письма редактора» (карточки-конверты).
3. **Мастерская** (`StudioPage` + stage-страницы): верстак-фон, 7 этапов на StageStepper — иконки-инструменты (колба-концепт, глобус-мир, свиток-лор, портреты-персонажи, сундук-предметы, карта-сюжет, стопка-главы), карточки этапов — «чертежи/кальки».
4. **Доска сюжета** (новый роут `/books/:id/board`): пробковая доска, стикеры из `book_notes` (thread/foreshadow/arc/theme/mystery — данные уже есть), цвет стикера по типу, красные SVG-нити (bezier) связывают заметки одного треда/арки в хронологии глав. Drag-панорама доски. MVP — read-mostly: создание/редактирование заметок остаётся за существующими механизмами.
5. **Архив** (`Settings`/`Usage`/`StyleProfiles`): лёгкая ресценография «комод с ящиками» — ярлыки-шильдики на секциях. Минимальный объём.

## 6. Техническая архитектура

- **Токены**: замена значений в `:root` `library-warm.css` + новые атмосферные токены. Plain `:root`, не `@theme` (Tailwind v4 tree-shaking — известное ограничение).
- **Атмосферные компоненты** (`apps/web/src/components/atmosphere/`): `DustLayer`, `CandleGauge`, `CatCompanion`, `FocusMode` — presentational, `aria-hidden`, не трогают текст/роли/тест-селекторы → существующие тесты не ломаются.
- **Тумблер атмосферы**: контекст/хук `useAtmosphere()`, класс на `<html>`, чтение `prefers-reduced-motion`.
- **Тесты**: новые unit-тесты на логику (расчёт прогресса свечи, группировка нитей доски, редьюсер атмосферы). Атмосферные слои в тестах страниц не участвуют (рендерятся только в `atm-full`, jsdom-дефолт — `off`).
- **Зависимости**: ноль новых npm-пакетов.

## 7. Серверная часть

Единственная серверная работа этапа 1 — endpoint прогресса слов (`/api/writing-progress`). Этап 2 серверной работы не требует (доска читает существующие `book_notes` через существующий/минимальный read-endpoint). Если выбран вариант (б) с таблицей — одна hand-written миграция по официальному процессу (`docs/migrations.md`).

## 8. Риски и меры

| Риск | Мера |
|---|---|
| Canvas-анимации дают jank при вводе в TipTap | Пылинки отключены на ChapterPage при вводе; rAF-пауза при `document.hidden`; профилирование перед мержем |
| Скевоморфный китч | Проверка «помогает/мешает» на ревью каждой комнаты; `atm-calm` как эталон сдержанности |
| Регрессия существующего UI | `atm-off` = текущий вид; typecheck + полный тест-прогон на каждом инкременте |
| Ненадёжный подсчёт слов через дельту версий | Fallback — таблица `writing_days`, решение в плане |
| Палитра ломает контраст где-то в глубине UI | Ручной проход по всем страницам после смены токенов; чипы/тинты пересчитаны в спеке |

## 9. Вне скоупа

- Амбиент-звук (отклонён пользователем).
- Этап 3 «иллюстрированная сцена-хаб» (вариант C) — решение после этапа 2.
- Светлая палитра / переключатель день-ночь (выбрана одна палитра).
- Мобильная адаптация сценографии.
- Редактирование заметок на доске сюжета (MVP read-mostly).

## 10. Критерии успеха

1. `pnpm typecheck` и `pnpm test` зелёные после каждого инкремента.
2. `atm-off` визуально идентичен состоянию до этапа 1 (кроме палитры).
3. Набор текста в TipTap без заметного jank при включённой атмосфере.
4. `prefers-reduced-motion` полностью останавливает анимации.
5. Пользователь узнаёт метафору без подсказок: полка = книги, стол = глава, верстак = Studio, доска = сюжет.
