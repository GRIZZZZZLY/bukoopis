# Слайс 4.5 «Контракт главы» — план реализации

> **Для исполнителя:** ОБЯЗАТЕЛЬНАЯ ПОД-СКИЛЛ: `superpowers:subagent-driven-development` (рекомендуется) или `superpowers:executing-plans`. Шаги помечены `- [ ]`.

**Цель:** план главы говорит, что в ней **обязано** случиться, чего случиться **не должно**, какие тайны раскрываются и какие факты канона глава вправе отменить. Критик канона перестаёт считать запланированный поворот ошибкой, а редактор замечает невыполненное обещание плана.

**Архитектура:** контракт — четыре списка в варианте поглавного плана (`chapterBeatSheetVariantSchema`), необязательные в хранилище и обязательные в тулсхеме планировщика — тот же приём, что у `architecture` и `closing`. Планировщик получает действующие факты канона (сегодня их видит только Writer) и потому может назвать отменяемый факт по идентификатору, а не только словами. Рендер контракта — одна функция в `packages/shared`, её читают Writer, критик канона и редактор. Миграции не нужны: `plan_json` — это JSON.

**Технологии:** те же. Новых зависимостей и таблиц нет.

**Спека:** `docs/superpowers/specs/2026-09-05-character-individuality.md`, раздел 18 (строка слайса 4.5), раздел 3.1 пункт 4, раздел 10. Решение 10: отдельный слайс до этапа 5, своё утверждение.

## Глобальные ограничения

- В коммит идут **только файлы своей задачи**; `git add -A` запрещён.
- Каждая задача заканчивается зелёными `pnpm typecheck` (по имени, 7 пакетов) и `pnpm test`.
- Схемы хранилища остаются терпимыми к старым строкам: `plan_json`, написанный до слайса, обязан читаться без ошибки.
- Ничего не утверждается без автора: контракт приходит вариантом плана и вступает в силу только с выбором варианта.
- Правило проекта: модельный ответ не доверенный оттого, что он правильной формы. Контракт — это обещание плана, а не доказательство; критик по-прежнему требует цитату.

### Задача 1: Контракт в контракте плана

**Файлы:**
- Изменить: `packages/shared/src/plot.ts`
- Тест: `packages/shared/src/plot.test.ts` (существует)

**Интерфейсы:**
- Производит: `chapterContractSchema`, `ChapterContract`, `canonSupersessionSchema`, `renderChapterContract`, поле `contract?: ChapterContract` у `chapterBeatSheetVariantSchema`.

```ts
/** Отмена факта канона, запланированная автором сюжета. `factId` в форме
 *  `fact_<id>` — тот же вид ссылки, что у извлекателя; он есть, только если
 *  планировщик видел этот факт в списке действующих. `statement` обязателен
 *  всегда: по нему критик сопоставляет отмену, когда идентификатора нет. */
export const canonSupersessionSchema = z.object({
  factId: z.string().regex(/^fact_\d+$/).nullable().default(null),
  statement: z.string().min(1).max(300),
  /** Чем это становится после главы. */
  becomes: z.string().min(1).max(300),
});

export const chapterContractSchema = z.object({
  /** Что обязано случиться. Без этого глава не выполнила план. */
  mustHappen: z.array(z.string().min(1).max(300)).max(8).default([]),
  /** Чего в этой главе быть не должно: рано раскрытая тайна, встреча,
   *  которая назначена позже, смерть, которая нужна живой. */
  mustNotHappen: z.array(z.string().min(1).max(300)).max(8).default([]),
  /** Что читатель узнаёт именно здесь. Упоминание такого без подготовки —
   *  не дефект: оно запланировано. */
  expectedRevelations: z.array(z.string().min(1).max(300)).max(8).default([]),
  /** Факты канона, которые глава вправе отменить. */
  allowedCanonSupersessions: z.array(canonSupersessionSchema).max(8).default([]),
});
```

`renderChapterContract(c)` возвращает `null`, когда все четыре списка пусты, иначе русский блок с заголовком «Контракт главы» и четырьмя подсписками (пустые подсписки не печатаются — пустой заголовок читается как «ничего не запрещено», а это неправда, это «не задано»).

```ts
describe("контракт главы", () => {
  it("старый план без контракта читается", () => {
    const r = chapterPlanSchema.safeParse({
      variants: [{ label: "v1", pov: "Рин", emotionalGoal: "страх",
        estimatedWords: 1200,
        beats: [b(), b(), b()] }],
      selectedIndex: 0, generatedAt: "2026-01-01T00:00:00.000Z",
    });
    expect(r.success).toBe(true);
    expect(r.success && r.data.variants[0]?.contract).toBeUndefined();
  });

  it("пустой контракт не рисует заголовка", () => {
    expect(renderChapterContract({ mustHappen: [], mustNotHappen: [],
      expectedRevelations: [], allowedCanonSupersessions: [] })).toBeNull();
  });

  it("печатает только непустые списки", () => {
    const out = renderChapterContract({
      mustHappen: ["Рин находит медальон"],
      mustNotHappen: [], expectedRevelations: [],
      allowedCanonSupersessions: [
        { factId: "fact_12", statement: "брат погиб", becomes: "брат жив" },
      ],
    })!;
    expect(out).toContain("Контракт главы");
    expect(out).toContain("Рин находит медальон");
    expect(out).toContain("fact_12");
    expect(out).toContain("брат жив");
    // Пустое не печатается: заголовок без строк читается как «ничего не
    // запрещено», тогда как на деле это «не задано».
    expect(out).not.toMatch(/Чего быть не должно/);
  });

  it("отмена без формулировки отвергается, без идентификатора — нет", () => {
    expect(canonSupersessionSchema.safeParse({ statement: "", becomes: "x" }).success).toBe(false);
    const ok = canonSupersessionSchema.safeParse({ statement: "брат погиб", becomes: "брат жив" });
    expect(ok.success).toBe(true);
    expect(ok.success && ok.data.factId).toBeNull();
  });
});
```

### Задача 4: Критики различают запланированное и случайное

**Файлы:**
- Изменить: `packages/agents/src/critics/canon.ts`, `packages/agents/src/critics/editor.ts`, `packages/agents/src/critics/base.ts` (поле `chapterContract` у `CriticInput`), `apps/server/src/utils/chapter-prose-context.ts` (прокинуть контракт)
- Тест: `packages/agents/src/__tests__/critics-contract.test.ts` (создать)

Критик канона: факт, названный в `allowedCanonSupersessions`, изменён — это **не** замечание; изменён факт, там не названный, — замечание прежней тяжести. Раскрытие из `expectedRevelations` — не «упоминание без подготовки».

Редактор: пункт `mustHappen`, которого в главе нет, — `blocking`; нарушенный `mustNotHappen` — `blocking`; нераскрытая `expectedRevelations` — `suggestion`. Цитата обязательна по общему правилу, а для «не случилось» цитаты нет — поэтому для таких замечаний прямо разрешено её отсутствие, и это единственное исключение; оно названо в промпте.

- [ ] **Шаг 1: Падающий тест** — промпты канона и редактора содержат правила выше; `buildCanonPrompt` и `buildEditorPrompt` печатают контракт; без контракта промпты не меняются (старые главы).
